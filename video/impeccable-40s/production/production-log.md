## 实际制作方法

- 输入：已有真实页面截图与录影、项目留证报告、用户社群视频规范。
- 制作：Remotion 4.0.539 + React；独立 Scene，静态关键帧检查后再渲染。
- 合成：本地 FFmpeg。不是 AI 生成的网页或操作画面。
- 临时旁白：macOS say，Tingting，190 words/min；按短句生成 WAV，保留原始时长，不加速音频。
- 输入文字：`src/guide-audio.json` 的每个 `text` 字段，与锁定脚本对应。
- 付费模型 / Endpoint / Prompt / job ID：无；未提交任何生成式 API 任务。
- 新增付费 API 成本：$0。

## 草稿输出检查

`previews/animatic-v02.mp4`：720×1280、30fps、1200 帧、40.000 秒；音轨 40.000 秒。全片解码通过，逐段取样帧人工检查通过。音轨测得 -18.57 LUFS、真峰值 -5.72 dBTP，无削波；这是临时旁白电平，最终配音后需重做混音。字幕文件按各句真实 WAV 时长导出，帧量化误差不超过一帧。

合成时发现 Remotion 自带 FFmpeg 未启用视频 setpts 与 volumedetect，改为保留各片段的零起始视频时间戳并使用 loudnorm 测量；没有重渲染无关片段。
