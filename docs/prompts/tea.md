# T01 — 山間製茶 / Seasonal Tea Subscription

請在這個現有 Vite 專案製作「山間製茶」的單頁 Landing Page，直接編輯 experiments/tea/index.html，路徑 /experiments/tea/。這是虛構的台灣小批次茶訂閱品牌，內容為展示設定，不是實際商品。主要文案使用繁體中文，少量英文可作輔助，但不能搶走中文的閱讀層級。

產品：每季寄出兩款台灣茶與一張沖泡卡，幫助想把喝茶變成日常、卻不熟悉茶葉分類的都市上班族。核心句：「把一座山，留給一杯茶。」主要 CTA「選擇這一季的茶」，次 CTA「看看怎麼沖」。目標是讓訪客理解風味與訂閱方式，不用堆砌文青形容詞。

必備內容：
1. 有辨識度的 Hero，傳達茶的產地、時間與日常儀式，避免套用 SaaS 功能卡布局。
2. 本季兩款茶，全部標示為示範商品：阿里山烏龍，50g，清花香／柔和甘甜；南投紅玉，50g，肉桂香／清涼尾韻。產地只使用以上設定，不捏造茶農人名、海拔、認證或獲獎。
3. 兩種方案：季付 NT$980／季、年付 NT$3,600／年（四次寄送）。每次兩款各 50g，含沖泡卡；台灣本島免運，離島運費尚未提供，需清楚說明。取消規則：下次出貨七日前可取消後續續訂；不杜撰退款承諾。
4. 三個步驟：選擇方案 → 每季收茶 → 按卡沖泡。加入可切換兩款茶的沖泡指南：烏龍 95°C、150ml、第一泡 60 秒；紅玉 90°C、150ml、第一泡 45 秒。
5. FAQ：如何保存？何時寄送？可以取消嗎？保存建議保持密封、避光、乾燥；示範寄送日在每季首月 15 日。

互動：季付／年付切換會更新價格、寄送次數和摘要；主 CTA 移到方案區；「預覽訂閱」打開頁內訂單摘要，明確說明不付款、不送出訂單；沖泡指南可切換，FAQ 可展開。不要加入後端、登入、付款或電子郵件收集。

設計開放給你決定。用排版、留白與有意義的影像，表達台灣茶的具體氣味與觸感；避免把所有精品品牌都做成米色背景加英文斜體襯線字。允許照片、實物靜物或具有品牌感的插畫，但不能用空的圖片框當交付。素材若來自外部需附來源，AI 生成需附完整 Prompt，不能暗示示意照片來自真實品牌。

實作限制：保持原生 HTML/CSS/JS，只修改 experiments/tea/ 下的檔案；不要改工作台、其他頁面、官方 baseline 或 package.json。不要引入 UI 框架。桌面 1440×900、手機 390×844 和 360×800 可用；測試中文長標題、200% 縮放與鍵盤；尊重 prefers-reduced-motion。字級、對比與商品資訊的易讀性優先於裝飾。

交付：完成頁面、實際執行 npm run build，檢查桌面與手機渲染。列出視覺決策、素材來源、所有額外 Prompt、檢查結果和已知問題；不要宣稱進行了未執行的檢查。
