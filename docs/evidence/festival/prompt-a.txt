請在這個現有 Vite 專案製作「OFFGRID 離線聲場」的單頁 Landing Page，直接編輯 experiments/festival/index.html，路徑 /experiments/festival/。這是一場虛構的台北實驗電子音樂與視覺藝術活動，所有演出者、場地及票種都是展示設定，頁面須明確標示「虛構活動・設計測試」。

受眾：願意探索陌生聲音的 20–35 歲音樂與設計愛好者。主張：「把訊號關掉，把感官打開。」主要文案繁體中文，演出者名稱與必要資訊可用英文。頁面應具有能當成海報的辨識度，但訪客必須能迅速找到日期、場地、票價與時刻表。

固定內容：
1. 活動日期 2027.05.22，14:00–22:00；場地「台北・聲場倉庫（虛構場地，無實際地址）」；主 CTA「查看票種」、次 CTA「探索陣容」。
2. 兩個舞台：SIGNAL 和 NOISE。六組虛構演出者與時間：SIGNAL 14:00–15:00 MOSS CIRCUIT、16:00–17:00 低頻植物、18:00–19:00 SOFT ERROR；NOISE 15:00–16:00 玻璃海、17:00–18:00 NULL FM、20:00–22:00 夜間格式。
3. 時刻表能切換全部／SIGNAL／NOISE。舞台、時間、表演者不能只靠顏色區別；手機上仍要看得懂。
4. 票種：早鳥 NT$980（已售完）、一般 NT$1,280（可預覽）、雙人 NT$2,200（可預覽）。不要捏造庫存倒數、購票人數或稀缺性。
5. FAQ：是否有年齡限制？未滿 18 歲需監護人陪同（活動設定）；是否可攜帶外食？場內不開放；無障礙動線？示範規劃提供無階差入口與休息區，不宣稱實地驗證。

互動：點擊演出者可在頁內展開一段虛構風格介紹；篩選舞台保留清楚的時間排序；票種按鈕打開頁內票券摘要，顯示票種、單價與張數，可加減 1–4 張並更新總價。早鳥按鈕不可選。最後顯示「這是設計測試，不會產生訂單」。不串金流，不收個資。鍵盤使用者能操作所有控制。

視覺挑戰：請大膽處理繁中與拉丁字的尺度、節奏、密度和非對稱構圖。允許高飽和色、幾何構成與適量動態。不要為了海報效果犧牲核心資訊，不能把文字轉成圖片、不能強制接管捲動、不能自動播放音樂、不能閃爍。尊重 prefers-reduced-motion，關閉動畫後仍有完整構圖。

實作限制：保持原生 HTML/CSS/JS，只修改 experiments/festival/ 下的檔案；不要改工作台、其他頁面、官方 baseline 或 package.json。不要引入 UI 框架。桌面 1440×900、手機 390×844 和 360×800 可用；繁中長名稱不截斷；檢查 200% 縮放、對比與鍵盤焦點。外部或 AI 素材均記錄來源或完整生成 Prompt。

交付：完成頁面、實際執行 npm run build，檢查桌面與手機渲染。說明視覺決策、動態降級方式、所有額外 Prompt、檢查結果和仍未解決的問題。
