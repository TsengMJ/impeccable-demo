The agent acts. You draw the envelope.

AEGIS does not hand over your wallet. You grant a narrow, revocable mandate: how much, what action, which protocol, and for how long. The agent cannot exceed it.

  1. Set the ceiling

    Daily spend limit and allowed action (swap or transfer).

  2. Bound the path

    Protocol and duration lock where and when the agent may act.

  3. Revoke anytime

    One control stops every pending and future action under that grant.

    This page is a concept interface. It is not connected to a real wallet, smart contract, or security audit. The rules below describe the intended product model.

    • Least privilege by default

      The agent receives only the action, protocol, amount, and window you set — nothing broader.

    • Simulate before send

      Intended flow checks each request against your mandate before any on-chain step would run.

    • Revoke stops everything

      Withdrawing authorization blocks pending and future actions under that grant immediately.
